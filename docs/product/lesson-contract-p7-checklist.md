# 레슨계약서 v2 P7 — DEV 폰 점검표

범위: 레슨계약서만(회원권계약서·상담·인사이트는 범위 밖). DEV 앱(`com.morethanfitness.app.dev`)과 DEV 서버(`more-than-fitness-dev-mft`)에서 실행한다.
점검은 **테스트 회원**으로 한다. 파기·해지는 되돌릴 수 없다. 결과는 표의 `결과` 칸에 ○ / × / 메모로 적고, ×가 있으면 화면 캡처와 함께 전달한다.

## A. 계약 흐름

| # | 시나리오 | 확인할 것 | 결과 |
|---|---|---|---|
| A1 | 계약서가 없는 회원 | 회원카드 계약서 아이콘 → 이 회원의 계약서 목록이 비어 있고 `새 계약서` 진입이 된다 | |
| A2 | 작성 중(임시저장) | 입력 중 나갔다 들어와도 이어서 쓴다. 필수 칸 누락 시 첫 칸으로 이동하고 토스트가 뜬다 | |
| A3 | 서명 ①만 완료 후 앱 종료 | 앱을 껐다 켜도 `회원 서명 대기` → 서명 ②부터 이어진다 | |
| A4 | 서명 ②까지 | `강사 서명 대기`에서 강사 서명으로 이어진다. 내용을 고치면 서명이 무효가 되고 다시 받아야 한다 | |
| A5 | 완료 | 완료 화면, PDF 생성·열람 링크, 문자·카톡 공유, PDF 파일 저장 | |
| A6 | 재계약(완료된 회원에게 새 계약) | 회원카드 레슨 등록 칩이 `총 N / 잔여 M (+추가)`로 합산, 잔여 적음 주황·소진 빨강 | |
| A7 | 완료된 계약서 수정 시도 | 완료 계약서는 고칠 수 없고 안내가 뜬다 | |
| A8 | 환불 계산 예시·금지 문구 | 예시 값이 입력값과 맞고, `환불불가`·카드수수료 공제 같은 문구는 입력이 막힌다 | |

## B. 파기와 해지

| # | 시나리오 | 확인할 것 | 결과 |
|---|---|---|---|
| B1 | 파기(완료 3일 이내, 레슨 전) | ⋮ → `계약 파기` → 사유 → 회원 서명 → 파기됨. 등록 횟수가 되돌려지고 회원카드·홈이 이전 상태로 돌아온다 | |
| B2 | 파기 서명 유사도 | 계약서의 회원 서명과 많이 다른 서명이면 다시 서명을 요구한다 | |
| B3 | 파기 불가 사례 | 레슨을 받은 뒤, 3일이 지난 뒤에는 파기 항목이 없거나 거부 안내가 뜬다 | |
| B4 | 해지(서명 없이) | ⋮ → `계약 해지` → 서명 끔 → `강사 단독 기록`으로 해지 기록 화면 | |
| B5 | 해지(회원 서명 포함) | `회원 서명 확인`으로 기록되고 서명 그림이 보인다 | |
| B6 | 해지 후 회원카드 | 총·잔여가 0(`미등록`)으로 바뀌고 `(+N)`이 사라진다. `만료 상태로 옮기기`를 켰으면 만료로 옮겨진다. 이어서 재계약하면 0에서 새로 시작한다 | |
| B7 | 해지 뒤 홈·레슨 확정 | 홈에 `계약 미완료` 표시가 자연스럽고, 레슨 확정이 이상하게 막히거나 중복 차감되지 않는다 | |
| B8 | 해지 전 보낸 PDF 링크 | 링크가 계속 열리고, 진위 확인 화면에 `체결 후 해지된 계약서`로 보인다 | |
| B9 | 해지 후 재계약 | 같은 회원에게 새 계약을 다시 완료할 수 있고 회원카드 계약 표시가 새 계약으로 바뀐다 | |
| B10 | 목록 | `해지됨`·`파기됨` 칩, 취소·파기 계약 기본 숨김/보기 토글, 해지 계약은 숨기지 않는다 | |
