## 0. 제품 구조 (먼저 이해해 주세요)
1. **자유 가입**: 누구나 가입. 소속·트레이너 직접 선택 목록은 **만들지 않습니다.** 트레이너 매칭은 차후 별도 시스템.
2. **1:1 연결(초대 링크)**: 강사가 초대 링크를 보내면 회원이 수락해 연결 → 레슨 알림·일정 공유·레슨 사인·채팅 (서버·로그인 방식 확정 후, 1.0.7 이후).
3. **커뮤니티 게시판**: 개인 운동·러닝은 코치에게 개별 전송하는 게 아니라 **게시판에 올리는 것**. 게시판은 **그룹** 단위.

### 그룹 (게시판 단위)
| 종류 | 만드는 사람 | 가입 | 표시 |
|---|---|---|---|
| 센터 그룹 | 강사(강사 앱 소속센터 연결) | 강사 초대 수락 | 인증 |
| 강사 그룹 | 강사(예: 강남, 관악) | 초대 시 강사가 그룹 선택 | 인증 |
| 자기기재 그룹 | 회원이 마이페이지에 소속 자유 입력(예: 모어댄짐, 타지역) | 입력하면 자동 합류 | **미인증** |
- 같은 표기(공백·대소문자 정규화)를 쓴 회원끼리 자동으로 모임. 소속 없는 회원은 "전체"만.
- **인증 그룹 게시판에는 초대 수락자만** 들어올 수 있음(자기기재로 진입 불가). 자기기재 그룹은 별도 게시판.
- 한 회원은 여러 그룹 소속 가능(기본 최대 3). 올릴 때 그룹을 고름.
- 트레이너는 자기 그룹 게시판을 **읽기만**, 글쓰기 불가.

## 1. 디자인 통일 (먼저 시작) — 강사 앱이 기준, 강사 앱은 바꾸지 않음
- 포인트 색 골드 `#EFCB62`. 현재 주황 모두 교체.
- **라이트·다크 지원**, 토큰(역할 이름)만 사용. 값 표는 지시서 1.5.
- 글자·아이콘 골드: 다크 `#EFCB62` / 라이트 `#856A22`. 골드 채움 위 글자는 남색 `#0B1E32`.
- 카드는 평평하게. 금지: 보라 헤더, 금속 광택, 파스텔 그라데이션, 파란 선택 테두리, 개발자용 안내문.
- 헤더: 곡선 남색 헤더 안에 영문 라벨 + 굵은 제목 유지.
- 레슨 블록 색은 `typeColorHex`만, 글자는 흰색/`#1F2937` 중 대비 큰 쪽 자동.

**1차**: 색 토큰·주황→골드, 공통 컴포넌트, 마이 화면 개발자 안내문 제거(출시 전 필수), 하단 바 안전 여백, 커뮤니티 오류 화면 중앙+다시 시도
**2차**: 운동 신체 이미지 파란 배경 제거+골드 선택색, 홈 2열 타일+빈 상태, 자동 우선순위(사인 요청→코치 미연결), 홈 타일 편집(기기 로컬)+자주 쓰는 것 추천(규칙 기반, 몰래 재배치 금지)

## 2. 기능 개발 방향 (디자인 후, 순서대로)
| 순서 | 기능 | 요약 | 선행 |
|---|---|---|---|
| 1 | SVG 개인 운동일지 | 부위 탭→운동→세트·무게·시간. 기본 나만 보기, "게시판에 올리기"로 그룹에 게시 | SVG 부위 ID 매핑표(안정 ID) 먼저 |
| 2 | GPS 러닝 | 거리·시간·페이스·경로선(지도 SDK 없이). 포그라운드 서비스, 백그라운드 위치 권한 요청 안 함 | 위치정보 법적 확인 |
| 3 | 채팅 | 연결된 코치와 1:1 텍스트 → 카드 메시지(사인·계약·레슨일지 요약) | 연결 API·로그인 방식 |
| 4 | 강사 영상 | 부위·운동명에 묶어 "내 코치 영상". 링크 먼저, 업로드는 요금제 결정 후 | 강사 앱 영상 단계 구현 |
- 게시판 카드는 요약(운동·세트·시간, 러닝 거리·시간·페이스)이 기본. **러닝 경로·통증 메모·몸 사진은 올릴 때 회원이 직접 포함한 경우만.**
- 관심사 태그: 가입 직후 온보딩, **전체 최대 5개**, 건너뛰기 가능, 마이에서 수정. "기타" 직접 입력은 사장님이 검토 후 표준 목록 반영(실적 집계 제외).

## 3. 승인·주의
- **새 패키지 범주 승인됨**: SVG 렌더링, 위치·포그라운드 서비스, 영상 재생. **구체 패키지 이름·버전은 추가 직전에 목록으로 보고**.
- 승인 없이 하지 말 것: Firebase Rules·Functions·인덱스, 새 컬렉션/필드, 결제, 로그인 방식, 개인정보·동의, 사인 출석 서버 API, 패키지 ID 변경.
- `training_logs`는 draft(`status:"draft"`)가 먼저 생김 → 회원앱 쿼리에서 draft 제외.
- 레슨일지 원본은 트레이너만 읽음. 회원에게는 강사가 보낸 요약 카드만(카드 저장 위치는 확인 후 공유).
- 법적 확인(건강·위치·사진·14~17세) 결과가 나오기 전에는 해당 기능을 출시하지 않음.
- 강사 앱 쪽 작업(그룹 만들기, 초대 링크 등)은 `trainer-app-feature-work-order.md`로 따로 진행되며, 서버 API가 확정되면 회원앱에 인터페이스를 공유합니다.
