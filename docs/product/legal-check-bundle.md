# 법적 확인 묶음 (전문가 확인용 체크리스트)

작성: 2026-11-11. 상태: **법률 자문이 아니라 확인할 질문 목록.** 법적 판단은 변호사·개인정보 전문가 확인이 필요하다. 아래 법령명은 확인 대상 후보이며 조항·최신 내용은 전문가가 검증한다.

## 1. 회원 가입·연령
- 만 14세 미만 가입 제한(가입 시 생년 확인 방식)과 만 14~17세 회원의 동의·기본 공개 범위
- 필요한 동의 항목 분리: 필수(이용약관·개인정보 수집), 선택(마케팅), **민감정보(건강)**, **위치정보**

## 2. 건강 정보·민감 정보
- 재활·통증 메모, 체중·인바디·눈바디 사진, 관심사 건강 태그가 민감정보에 해당하는지, 별도 동의 문구
- 강사에게 공유할 때의 동의 방식(연결 수락 + 항목별 켜기)과 철회 시 처리
- 보관 기간, 탈퇴·연결 해제 시 삭제 범위

## 3. 위치정보 (GPS 러닝)
- 개인위치정보 수집·이용 동의, 처리방침 반영, 사업자 신고·허가 필요 여부
- 경로 공유 시 노출 완화(출발·도착 가림) 충분성
- 포그라운드 서비스 알림 표시 및 스토어 위치 권한 심사 대응

## 4. 커뮤니티·게시물
- 게시 중단 요청(임시조치) 처리 절차, 신고·숨김·정지 운영 기준 공지
- 광고 표시(트레이너 프로필 광고의 "광고" 표기), 연락처·가격 홍보 금지 조항
- 특정인 비방 게시물 처리와 운영자 책임 범위
- 사진: 얼굴·타인 초상, 노출 사진 금지, 14~17세 사진 공개 범위

## 5. 트레이너·강사 저작물·초상
- 강사 운동 영상의 저작권·이용 허락 범위, 회원 시청 한정·재배포 금지 문구
- 영상에 등장하는 회원 초상 동의(레슨 영상 촬영 시)

## 6. 매칭·추천
- 성과 집계 노출("같은 목표 회원 N명")의 정확성·표시광고 문제, 최소 집계 인원 기준
- 의료 오인 표현 금지(치료·진단 암시 문구), 상표 표시(MORE THAN / wellness) 검토

## 7. 전달 방법
위 7개 묶음을 한 번에 자문받도록 정리했다. 사장님이 자문 창구를 정하면 이 문서를 그대로 전달한다. **자문 결과가 나오기 전에는 건강정보·위치정보·사진 관련 기능을 출시하지 않는다.**
