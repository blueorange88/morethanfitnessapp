# 앱 1.0.7 전체 점검표

기준: 직전 릴리스 `7744027`(1.0.6+26) 이후 `docs/agent/RUN_LOG.md`에 기록된 변경 전체. 현재 DEV 앱(`com.morethanfitness.app.dev`)으로 점검하고, 릴리스 뒤에는 맨 아래 **PROD 확인**을 한 번 더 한다.
레슨계약서 흐름 자체는 `lesson-contract-p7-checklist.md`(A·B 완료)에서 이미 확인했으므로 여기서는 **계약서 외 기능과 계약서와 맞닿는 화면**을 본다.
결과는 `결과` 칸에 ○ / × / 메모로 적는다. ×는 화면 캡처와 함께 전달한다. 모든 항목은 **라이트·다크 모드 둘 다** 본다(표시된 것만 다크 필수가 아니라 전부 해당).

## 1. 회원 리스트 (월렛식 겹친 카드)

| # | 확인할 것 | 결과 |
|---|---|---|
| 1-1 | 회원 리스트가 겹친 카드로 보이고, 카드를 누르면 고객카드로 **천천히 확장**되며 열린다(눌림 효과·금빛 번짐, 올라올 때 어색하지 않음) | |
| 1-2 | 맨 위의 황금색 `회원 등록` 카드가 보이고 문구가 바뀌며, 누르면 등록 화면이 열린다 | |
| 1-3 | 카드를 눌렀을 때 탭이 안 먹히거나 맨 밑 카드가 잘리지 않는다. 내비게이션 바에 가리지 않는다 | |
| 1-4 | 활동·휴면·만료 구분이 보이고, 휴면·만료 회원을 **그룹처럼 옮길 수** 있다 | |
| 1-5 | 회원이 많을 때(스크롤)·검색 시 느려지거나 깜빡이지 않는다 | |

## 2. 고객카드

| # | 확인할 것 | 결과 |
|---|---|---|
| 2-1 | 고객카드 헤더가 전폭의 떠 있는 카드 모양이고(윗모서리 둥글게, IC 칩, 홀로그램 씰), 던지듯 쓸면 **뒤집힌다** | |
| 2-2 | 헤더를 **접으면** 카드 윗부분만 남고, 겹친 가장자리가 어색하지 않다. 다시 펼쳐진다 | |
| 2-3 | 기본 등급 표시가 `BRONZE`로 시작한다(신규 회원) | |
| 2-4 | 회원카드의 레슨 등록 현황이 **한 줄**로 나오고 글자가 너무 작아지지 않는다. 잔여 적음 주황·소진 빨강 | |
| 2-5 | 하단 바: `레슨계약서`(새로 작성) ↔ `레슨일지` 순서, 스크롤하면 숨고 나타난다(저장 중에는 안 숨음) | |
| 2-6 | 상단 계약서 아이콘 → 이 회원의 계약서 목록, ⋮ → `지난 레슨계약서` → 같은 목록(대화창 없음) | |
| 2-7 | 계약서가 연결된 회원은 횟수를 카드에서 직접 못 바꾼다는 안내, 계약서가 없는 회원은 직접 입력된다 | |
| 2-8 | `회원권 관리`(정지 이력·회원권계약서)와 정지·재개 동작이 그대로다 | |
| 2-9 | 회원 저장·수정·삭제, 동의서 받기 흐름이 그대로 동작한다 | |

## 3. 홈 (스케줄러·레슨 시트)

| # | 확인할 것 | 결과 |
|---|---|---|
| 3-1 | 일정을 눌러 레슨 시트를 열면 헤더 색·회원 이름 옆 `총 N / 잔여 M (+X)` 칸이 보인다 | |
| 3-2 | AIFC 추천업무 칩 순서: `신규계약서` → `회원카드` → `레슨일지` → `서명요청`(한 줄, 겹치지 않음) | |
| 3-3 | `신규계약서`를 누르면 레슨/회원권 선택 시트가 뜨고 둘 다 열린다. 회원권 선택 시트가 다크 모드에서 어둡다 | |
| 3-4 | AI 레슨 추천 회원 아바타·`오늘/다음 레슨` 색이 자연스럽다 | |
| 3-5 | **레슨 확정**(홈에서 확정) → 횟수 1 차감, **확정 취소** → 복원. (서버 함수 `finalize`/`cancel` 수정이 PROD에 나가므로 반드시 확인) | |
| 3-6 | 빠른 서명(레슨일지 서명) 후 확정이 정상이고, 중복 차감이 없다 | |
| 3-7 | 햄버거 메뉴: `회원리스트`, `계약서 관리`, `인사이트`, `브랜딩 굿즈`, 설정이 열린다 | |
| 3-8 | 일정 삭제 후 되살아나지 않는다(기존 이슈 재확인) | |

## 4. 홈 화면 위젯 4종 (PROD 빌드에서 한 번 더)

| # | 확인할 것 | 결과 |
|---|---|---|
| 4-1 | 위젯 목록에 `모어댄 주간 일정`, `모어댄 다음 레슨`, `모어댄 오늘 레슨`, `모어댄 지금·다음`이 보인다 (PROD는 이름에 `DEV`가 없다) | |
| 4-2 | `오늘 레슨`(2×4 세로 목록): 시간 순 목록, 진행 중 레슨은 `지금`/`다음` 선으로 감싸짐, 앱 위젯 테마 6종에 맞춰 색이 바뀐다 | |
| 4-3 | `지금·다음`(2×2): 전/지금/다음 세 줄, 레슨 시작·종료 시각에 칸마다 굴러간다 | |
| 4-4 | `지금·다음`: 위 줄 탭 = 이전 레슨 훑어보기, 아래 줄 탭 = 다음 레슨, **6초 뒤 현재로 복귀**, 가운데 줄 탭 = 앱의 오늘 일정 | |
| 4-5 | `지금·다음` 위젯 선택 목록 미리보기가 뜨고 예시 이름이 홍길동·이순신·신사임당이다 | |
| 4-6 | 자정이 지나면 위젯의 날짜가 바뀌고, 주간 위젯의 현재 시간 표시가 맞다 | |
| 4-7 | 앱에서 일정을 바꾸면 위젯이 갱신된다. 위젯을 눌러 앱이 열린다 | |
| 4-8 | 설정 → 위젯 설정에서 테마를 바꾸면 위젯 색이 따라 바뀐다 | |

## 7. 계약서와 맞닿는 곳 (스모크)

| # | 확인할 것 | 결과 |
|---|---|---|
| 7-1 | 새 테스트 회원으로 계약 작성 → 서명 → 완료 → PDF 링크 → 해지(`미등록`으로 바뀜) → 재계약(0에서 시작) 한 바퀴 | |

| 7-4 | 햄버거 `계약서 관리` → 목록, 검색, `새 레슨계약서 작성`, `회원권계약서 작성` | |

## 8. 계정·환경

| # | 확인할 것 | 결과 |
|---|---|---|
| 8-1 | 레거시 관리자 계정으로 로그인해 기존 계약서·회원 화면이 그대로 동작한다(햄버거는 `레슨계약서`·`회원권계약서` 두 항목) | |
