# 커뮤니티 인증 사진 정책 — 기본틀 (팀 논의용 초안)

작성: 2026-11-11. 상태: **결정 전 틀.** 값은 일반 커뮤니티 관행을 기준으로 한 제안이며 확정이 아니다. 서버·요금제·개인정보에 걸려 있어 구현 전에 사장님 승인이 필요하다(AGENTS.md).
관련: `member-app-work-order.md` 3.3, `ultimate-goal-trainer-member-matching` 방향.

## 1. 단계
- 1단계: 글 + 체크형 기록만(사진 없음).
- 2단계: 사진 인증. 회원 수와 비용을 본 뒤 오픈. 아래 항목을 팀이 채운다.

## 3. 확인할 것 (법적·기술)
- 개인정보 보호법: 얼굴 사진 처리 고지, 만 14세 미만 가입 불가 유지, 보관·삭제 기간 명시
- 정보통신망법: 게시 중단 요청 처리 절차
- 이용약관·커뮤니티 규칙에 금지 사진 조항 반영
- Firebase Storage 요금제(현재 "무료 범위 운영" 방침과 충돌 여부)
- 사진 접근 보안 규칙: 공개 범위별 읽기 권한(Rules 변경 = 별도 승인)
