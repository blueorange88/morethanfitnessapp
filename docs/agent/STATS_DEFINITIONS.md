# 레슨 인사이트 지표 정의

작성일: 2026-07-14  
대상 화면: `lib/pages/stats_page.dart`

## 데이터 원칙

- 선택 기간의 일정은 Firestore `schedules` 컬렉션을 `startAt` 범위로 직접 조회한다.
- 삭제 표시(`isDeleted`, `deleted`, `voided`, `archived`, `deletedAt`) 또는 삭제 상태(`deleted`, `delete`, `removed`, `archived`, `voided`, `pending_delete`)가 있는 일정과 회원은 제외한다.
- 회원 현황은 Firestore `members` 컬렉션의 실제 저장 필드만 사용한다.
- 금액은 결제 금액과 결제일이 함께 확인되는 실제 수납 원천이 연결되기 전까지 계산하거나 추정하지 않는다.
- 홈에서 전달되는 `scheduleData`는 현재 주 기준 앞뒤 4주만 포함하므로 월간·3개월 통계의 원천으로 사용하지 않는다. 기존 생성자 호환을 위해 인자는 유지한다.
- 비율은 분모가 0이면 `-`로 표시한다.

## Phase 1 표시 지표

### 요약

| 지표 | 화면 표시 | 계산 | 포함 | 제외 | 기간 | 신뢰도 | 클릭 대상 |
|---|---|---|---|---|---|---|---|
| 완료 레슨 | `N회` | `lessonConfirmStatus == completed` 일정 수 | 선택 기간의 완료 확정 일정 | 삭제 일정, 다른 상태 | 선택 기간 | 높음 | 없음 |
| 예정 레슨 | `N회` | 현재 시각 이후의 미확정 일정 수 | 미래 일정 중 확정 결과가 없는 일정 | 삭제 일정, 이미 확정된 일정 | 선택 기간 | 높음 | 없음 |
| 실제 수업률 | `N.N%` | 완료 ÷ (완료 + 노쇼 차감 + 노쇼 미차감 + 서비스) × 100 | 결과가 확정된 실제 수업·노쇼·서비스 | 미확정, 취소 해제 일정 | 선택 기간 | 높음 | 없음 |
| 활성 회원 | `N명` | `memberStatus == 활성` 회원 수 | 삭제되지 않은 활성 회원 | 휴면, 만료, 삭제 회원 | 현재 상태 | 높음 | 없음 |

### 레슨

| 지표 | 코드/필드 | 비고 |
|---|---|---|
| 등록 레슨 | 선택 기간 `schedules` 문서 수 | 삭제 일정 제외 |
| 완료 | `lessonConfirmStatus == completed` | 확정 상태 원문 사용 |
| 노쇼·차감 | `lessonConfirmStatus == no_show_deducted` | 확정 상태 원문 사용 |
| 노쇼·미차감 | `lessonConfirmStatus == no_show_not_deducted` | 확정 상태 원문 사용 |
| 서비스 | `lessonConfirmStatus == service` | 확정 상태 원문 사용 |
| 요일 분포 | `startAt.weekday`별 등록 일정 수 | 선택 기간 기준 |
| 레슨 종류 비중 | `typeName` → `type` 순서로 분류 | 값이 없으면 `기타` |

`레슨 확정 취소`는 현재 취소 서비스가 일정의 확정 상태 필드를 삭제하므로 일정 문서만으로 이력을 정확히 셀 수 없다. Phase 1 숫자에서 제외하고, 추후 취소 감사 로그 또는 트레이닝 로그를 연결한다.

### 회원

| 지표 | 계산 | 포함/제외 | 기간 | 신뢰도 | 클릭 대상 |
|---|---|---|---|---|---|
| 활성 | `memberStatus == 활성` | 삭제 제외 | 현재 상태 | 높음 | 없음 |
| 휴면 | `memberStatus == 휴면` | 삭제 제외 | 현재 상태 | 높음 | 없음 |
| 만료 | `memberStatus == 만료` | 삭제 제외 | 현재 상태 | 높음 | 없음 |
| 기간 내 신규 | `createdAt`이 선택 기간 안인 회원 수 | `createdAt` 없는 회원은 제외 | 선택 기간 | 높음 | 없음 |
| 잔여 5회 이하 | 활성 회원 중 총 횟수 > 0이고 잔여 횟수 0~5 | `sessions.remain` → `remainSessions` → `remainingSessions` 순서 | 현재 상태 | 높음 | 없음 |
| 기간 내 회원권 만료 예정 | 활성 회원 중 `membership.endAt`이 현재 이후이며 선택 기간 종료 전 | 종료일 없는 회원 제외 | 현재~선택 기간 종료 | 높음 | 없음 |
| 14일 이상 미방문 | 활성 회원 중 `lastLessonAt` 또는 `lastLogAt`이 오늘보다 14일 이상 이전 | 방문 기록 없는 회원은 별도 의미이므로 제외 | 현재 상태 | 높음 | 없음 |

회원 행동 카드의 기존 회원 목록 필터 연결은 현재 통계 화면과 회원 목록 간 공용 필터 계약이 없어 Phase 1 후속 작업으로 남긴다. 숫자는 정확히 계산하되 클릭 가능한 것처럼 표현하지 않는다.

### 수입

| 표시 | 이유 | 후속 연결 |
|---|---|---|
| `데이터 연결 준비 중` | 현재 화면에서 확인 가능한 계약 상품 금액이나 일정 수는 실제 수납액·결제일을 보장하지 않는다. | 결제 완료 금액과 결제일이 있는 수납 원천을 연결한 뒤 확정 수입만 합산한다. 예상 수입은 별도 라벨과 별도 계산 근거가 있을 때만 분리 표시한다. |

## 기간 정의

- 이번 주: 사용자의 로컬 시간 기준 월요일 00:00 이상, 다음 월요일 00:00 미만
- 이번 달: 이번 달 1일 00:00 이상, 다음 달 1일 00:00 미만
- 3개월: 두 달 전 1일 00:00 이상, 다음 달 1일 00:00 미만
- 직접 선택: 선택한 시작일 00:00 이상, 종료일 다음 날 00:00 미만

Firestore 범위는 시작 포함·종료 미포함으로 통일한다.
