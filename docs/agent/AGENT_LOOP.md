# AGENT_LOOP

## 안전한 기본 모드
이 프로젝트는 `승인형 + 제한된 자동 루프`로 운영한다.

### 한 작업의 루프
분석 → 재현 → 계획 → 작은 수정 → 포맷 → analyze → 관련 테스트 → 전체 테스트 → debug build → 결과 기록 → 중단

### 자동 진행 허용
- 저장소 읽기
- 요청 범위 내 코드 수정
- Dart 포맷
- analyze/test/debug build
- 실패 원인 분석과 동일 작업 내 재수정
- 문서/RUN_LOG 갱신

### 반드시 중단
- 새 패키지/플러그인 추가
- Firestore/Storage Rules 변경 또는 배포
- Firebase Functions 배포
- 실제 데이터 삭제/마이그레이션
- 인증/결제/개인정보/계약서 정책 변경
- 대규모 파일 분리
- 같은 원인 3회 실패
- 빌드 성공 후 다음 백로그로 이동

## 실패 처리
1. 가장 먼저 출력된 구문/타입 오류를 우선한다.
2. 연쇄 오류는 각각 고치지 않는다.
3. 기존 오류와 새 오류를 분리한다.
4. 검증 환경 문제면 코드 변경을 중단하고 환경 문제를 보고한다.

## 결과 형식
- 목표
- 원인
- 수정한 파일
- 핵심 변경
- 실행한 검증
- 결과
- 수동 테스트 항목
- 남은 위험
- 다음 권장 작업
